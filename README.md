# what-did-i-say

턴이 끝날 때 "방금 무엇을 요청했는지 + 언제 요청했는지"를 한 줄로 다시 표시하고,
`/wdis N`으로 최근 N건을 조회하는 Claude Code 플러그인.

## 동작 예시

턴이 끝나면 Stop hook이 한 줄을 표시한다.

```
🗣 14:32 (12분 전) | 파서 필터 규칙 정리해줘
```

`/wdis 3` — 시간 오름차순으로 표시되며, `[1]`이 가장 최근 요청이다.

```
[3] 14:20 (25분 전) | 훅 등록 형식 확인해줘
[2] 14:32 (12분 전) | 파서 필터 규칙 정리해줘
[1] 14:44 (방금) | 테스트 케이스 추가해줘
```

오늘이 아닌 요청에는 날짜가 함께 표시된다.

```
[3] 08-08 23:10 (15시간 전) | 슬러그 규칙 실측해줘
```

## 설치

### 로컬 시험 (세션 한정)

플러그인 디렉터리를 지정해 Claude Code를 실행한다. 전역 설정을 건드리지 않고 해당 세션에만 로드된다.

```bash
claude --plugin-dir /절대/경로/what-did-i-say
```

세션 안에서 `/help` 또는 `/plugin`에 `wdis` 커맨드가 보이면 로드된 것이다.

### 마켓플레이스

token-keeper `plugins` 마켓플레이스 등록 후 제공 예정.

## 사용법

| 동작 | 방법 |
|---|---|
| 자동 표시 | 설치만 하면 턴이 끝날 때마다 최근 요청 한 줄이 표시된다 |
| 직전 요청 조회 | `/wdis` (기본 1건) |
| 최근 N건 조회 | `/wdis 3` |

- N이 숫자가 아니거나 1 미만이면 1건으로, 100을 초과하면 100건으로 보정하고 사유를 한 줄 안내한다.
- 다른 플러그인과 커맨드 이름이 겹치면 전체 이름 `/what-did-i-say:wdis`를 쓴다.
- 조회 결과에 `/wdis` 자신은 포함되지 않는다.

## 요구사항

- Node.js 18.17 이상 (외부 의존성 없음, stdlib만 사용)
- 플러그인·hooks를 지원하는 Claude Code 버전

## 알려진 한계

1. **현재 세션 한정** — 이전 세션의 요청은 조회되지 않는다.
2. **Claude Code 전용** — Codex는 지원하지 않는다 (transcript 포맷이 다르다).
3. **Stop 슬롯 공유** — 다른 플러그인·설정이 Stop hook을 함께 등록한 경우 출력 순서는 보장되지 않는다.
4. **mtime fallback** — 세션 ID를 얻지 못해 최근 수정 파일로 대체 탐색할 때, 같은 디렉터리에서 병렬 세션을 돌리면 다른 세션의 요청을 표시할 수 있다.

파싱 실패·파일 없음 등은 조용히 무출력으로 끝나며(exit 0), 세션 진행을 막지 않는다.

## 개발

```bash
node --test          # 27/27 통과
```

- `scripts/parser.mjs` — transcript jsonl을 끝에서부터 스캔해 사용자 요청만 골라낸다 (슬래시 커맨드 래퍼·hook 주입 컨텍스트·tool_result 제외).
- `scripts/wdis.mjs` — 진입점. stdin JSON을 받는 hook 모드와 `--list N` 조회 모드로 분기하고, 시간 포맷과 출력을 담당한다.
